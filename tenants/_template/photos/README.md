Положите сюда фотографии студии:

- logo.png — логотип для тёмного фона (светлый, PNG с прозрачным фоном)
- mark.png — знак для иконки приложения (квадратный, PNG с прозрачным фоном)
- hero.jpg — главное фото (горизонтальное, от 1600 px по ширине)
- work-1.jpg, work-2.jpg … — фото работ (пропишите их в tenant.json → gallery)

Фотографии владельца всегда важнее временных: просто замените файл и запустите `pnpm tenant:publish <название> --sync`.
